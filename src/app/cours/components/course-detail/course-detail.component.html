Introduction au HTTPS

HTTPS (HyperText Transfer Protocol Secure) est une extension du protocole HTTP qui utilise le chiffrement TLS/SSL pour sécuriser les communications. Ce protocole est essentiel pour protéger les données sensibles échangées entre le navigateur d'un utilisateur et un serveur web.

Fonctionnement de HTTPS

Le protocole HTTPS fonctionne en ajoutant une couche de sécurité au protocole HTTP standard :

  • Authentification: Vérifie l'identité du site web visité
  • Chiffrement: Protège les données échangées contre l'espionnage
  • Intégrité des données: Garantit que les données n'ont pas été modifiées

Avantages du HTTPS

  • Protection des données sensibles (identifiants, informations de paiement)
  • Amélioration du référencement sur les moteurs de recherche
  • Établissement de la confiance avec les utilisateurs
  • Intégration plus fluide avec les nouvelles API web

Certificats SSL/TLS

Les certificats SSL/TLS sont des fichiers numériques qui lient cryptographiquement une clé cryptographique aux informations d'une organisation. Un certificat contient :

  • Le nom de domaine pour lequel le certificat est validé
  • La personne, organisation ou appareil auquel il a été délivré
  • L'autorité de certification qui a émis le certificat
  • La signature numérique de l'autorité de certification
  • Paires de clés associées

Voir la solution + 
server { 
    listen 80;
    server_name example.com;
    
    # Redirigez HTTP vers HTTPS
    return 301 https://$host$request_uri;
}

server { 
    listen 443 ssl;
    server_name example.com;
    
    # Configuration du serveur HTTPS
    root /var/www/html;
    index index.html;
    
    # Paramètres SSL
    ssl_certificate /etc/ssl/certs/example.com.crt;
    ssl_certificate_key /etc/ssl/private/example.com.key;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_prefer_server_ciphers on;
    ssl_ciphers ECDHE-RSA-AES256-GCM-SHA512:DHE-RSA-AES256-GCM-SHA512:ECDHE-RSA-AES256-GCM-SHA384:DHE-RSA-AES256-GCM-SHA384;
    
    location / { 
        root /var/www/html;
        index index.html;
    }
}

Cette configuration:

  • Redirige tout le trafic HTTP vers HTTPS
  • Configure le serveur pour écouter sur le port 443 avec SSL
  • Spécifie l'emplacement des certificats
  • Limite les protocoles aux versions TLS 1.2 et 1.3 (plus sécurisées)
  • Configure des chiffrements sécurisés
